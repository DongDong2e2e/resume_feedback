# 🤖 나만의 AI 취업 컨설턴트

이 프로젝트는 Google Gemini와 로컬 Ollama를 함께 활용하는 하이브리드 AI 취업 컨설턴트입니다. 사용자가 지정한 폴더 내의 과거 지원 서류(성공/실패 이력서, 자기소개서), 기업 분석 자료 등을 기반으로, 새로운 채용 공고에 맞춰 자기소개서 초안에 대한 RAG(Retrieval-Augmented Generation) 기반의 심층 피드백을 제공합니다.

최신 버전에서는 **문서(PDF, DOCX 등)를 업로드하면 AI가 자동으로 핵심 내용을 분석하고 구조화된 '지능형 분석 노트'를 생성**하는 기능과, 다단계 프롬프트 체인을 통해 **'종합 분석', '항목별 피드백', '전체 수정 제안'**의 3단계를 포함한 깊이 있는 피드백을 생성하는 기능이 강화되었습니다.

## ✨ 주요 기능

-   **🎯 분리된 데이터 관리**: 사용자의 모든 데이터는 별도의 지정된 폴더(`1`~`4`번)에서만 관리되어, 프로젝트 코드와 학습 데이터를 명확하게 분리합니다.
-   **📊 3단계 심층 피드백**:
    1.  **종합 분석**: 역할별(인사팀, 실무팀장, 임원진) 평가와 핵심 역량 평가표를 통해 초안의 강점과 약점을 한눈에 파악합니다.
    2.  **항목별 피드백**: 자기소개서의 각 문단별로 구체적인 피드백과 개선 방향을 제시합니다.
    3.  **전체 수정 제안**: 모든 피드백이 반영된, 완성도 높은 최종 결과물을 제안합니다.
-   **🤖 AI 기반 지식 자동화**: PDF, DOCX 등의 파일을 업로드하면 AI가 내용을 분석해 **핵심 주제를 추천**하고, 표준화된 형식의 **'지능형 분석 노트(.md)'를 자동으로 생성**하여 지식 베이스를 구축합니다.
-   **🧠 Hybrid RAG**: 지정된 폴더 내의 로컬 문서와 최신 웹 정보(DuckDuckGo 검색)를 종합하여, 가장 관련성 높은 근거를 바탕으로 조언을 생성합니다.
-   **⚡ 실시간 스트리밍 응답**: LLM이 생성하는 답변을 실시간으로 확인할 수 있어 대기 시간을 최소화합니다.
-   **🔒 개인정보 보호**: 데이터 폴더는 `.gitignore`에 등록되어 Git에 추적되지 않으며, 민감한 정보가 외부로 유출될 위험을 방지합니다.

## 🛠️ 기술 스택

-   **Cloud LLM**: Google Gemini (`gemini-1.5-pro`, `gemini-1.5-flash`)
-   **Local LLM**: Ollama (`hf.co/Liontix/Qwen3-8B-Gemini-2.5-Pro-Distill-GGUF:Q4_K_M`)
-   **Embedding Model**: HuggingFace (`ibm-granite/granite-embedding-278m-multilingual`)
-   **Framework**: LangChain, Gradio
-   **Vector Store**: FAISS (Facebook AI Similarity Search)
-   **Language**: Python

## 📂 필수 폴더 구조

프로젝트를 올바르게 실행하려면, **프로젝트 최상위 경로(`resume_feedback`)**에 아래와 같은 폴더들이 반드시 존재해야 합니다. AI는 이 중 `1`번부터 `4`번까지의 폴더 내용만 학습 데이터로 사용합니다.

```
/resume_feedback/
```

## 🚀 설치 및 실행 방법

### 1. 사전 준비

-   **Python 3.8 이상**이 설치되어 있어야 합니다.
-   **Ollama**가 설치되고 실행 중이어야 합니다. ([Ollama 공식 홈페이지](https://ollama.com/)에서 다운로드)
-   **Google API 키**가 필요합니다. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급받을 수 있습니다.

### 2. 프로젝트 설정

1.  **프로젝트 다운로드 및 폴더 이동**
    이 프로젝트 파일들을 `C:\MS_AI_school\resume_feedback` 경로에 모두 다운로드하고, 터미널에서 해당 폴더로 이동합니다.

2.  **데이터 폴더 구성 및 파일 준비**
    위 `필수 폴더 구조`를 참고하여, `1`번부터 `5`번까지의 폴더를 모두 생성합니다. 그 후, 분석에 사용할 자신의 이력서, 자기소개서, 관련 자료 `.md` 파일들을 `1`~`4`번 폴더 내에 배치합니다.

3.  **파이썬 가상환경 생성 및 활성화**
    ```bash
    # 'venv-gpu'라는 이름의 가상환경 생성
    python -m venv venv-gpu

    # 가상환경 활성화 (Windows)
    .\venv-gpu\Scripts\activate
    ```

4.  **필요한 라이브러리 설치**
    ```bash
    pip install -r requirements.txt
    ```

5.  **Ollama 모델 다운로드**
    터미널에서 아래 명령어를 실행하여 `config.py`에 지정된 채팅 모델을 미리 다운로드합니다.
    ```bash
    ollama pull hf.co/Liontix/Qwen3-8B-Gemini-2.5-Pro-Distill-GGUF:Q4_K_M
    ```

6.  **.env 파일 생성**
    프로젝트 폴더에 `.env` 파일을 만들고, 발급받은 **Google API 키**를 입력합니다.
    ```
    GOOGLE_API_KEY="여기에_실제_API_키를_입력하세요"
    ```

### 3. 애플리케이션 실행

1.  **Ollama가 실행 중인지 확인**하세요.

2.  터미널에서 아래 명령어를 입력하여 Gradio 앱을 실행합니다.
    ```bash
    python app.py
    ```
    *최초 실행 시, HuggingFace 임베딩 모델과 NLTK 데이터 패키지를 자동으로 다운로드하며 시간이 다소 소요될 수 있습니다.*

3.  터미널에 나타나는 로컬 URL (`http://127.0.0.1:7860` 또는 유사한 주소)을 웹 브라우저에서 엽니다.

4.  **[중요] 벡터 DB 생성**: 앱을 처음 실행하거나, 데이터 폴더에 새로운 파일을 추가/수정한 후에는 반드시 **[자료 관리]** 탭으로 이동하여 **[벡터 DB 다시 만들기]** 버튼을 눌러주세요. AI가 최신 데이터를 학습하기 위해 필수적인 과정입니다.

## 💡 사용 방법

### 1. AI 컨설턴트에게 피드백 받기
-   **[AI 컨설턴트]** 탭으로 이동합니다.
-   '회사명', '직무명', '채용 공고', '자기소개서 초안'을 모두 입력합니다.
-   **[리포트 및 피드백 받기]** 버튼을 누르면 AI가 내 데이터를 바탕으로 맞춤형 피드백을 생성합니다.
-   피드백은 **[종합 분석]**, **[항목별 피드백]**, **[전체 수정 제안]** 3개의 탭으로 나누어 표시됩니다.

### 2. 자료 관리 및 AI 노트 생성
-   **[자료 관리]** 탭으로 이동합니다.
-   **AI 기반 자료 자동 정리**: PDF, DOCX 등의 문서를 업로드하여 AI가 분석하고 마크다운 노트(.md)로 자동 변환 및 저장하는 기능입니다. 이 기능을 통해 노트를 생성하면 벡터 DB는 자동으로 업데이트됩니다.
-   **수동 파일 관리**: `1`~`4`번 폴더에 저장된 모든 `.md` 파일을 직접 확인하고 수정할 수 있습니다.
-   **벡터 DB 다시 만들기**: 수동으로 파일을 추가/수정한 내용을 AI에게 학습시키려면 이 버튼을 꼭 눌러주세요.
